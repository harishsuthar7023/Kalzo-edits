# Kalzo Edits — Video Editing Portfolio

Modern, high-performance portfolio website for **Kalzo Edits**, dedicated to high-retention short-form video editing (Instagram Reels, YouTube Shorts, and brand storytelling).

## Features
- **Smart Autoplay**: Viewport-aware streaming reels on home timeline.
- **Work Grid**: 2-column mobile & desktop optimized grid of 40+ edits with instant click-to-play.
- **Original Anatomical Heart Logo**: Vector emblem representing *Kalzo* (काल्जो).
- **Direct Connect**: Instant WhatsApp (`6375751817`) and Instagram (`@kalzo_edits`) integrations.
- **Mobile & PC Workflow**: Fast turnaround, 4K 60FPS delivery.

## Tech Stack
- **React 19** + **Vite**
- **Vanilla CSS & TailwindCSS**
- **Lucide React Icons**

## Getting Started

### Install Dependencies
```bash
npm install
```

### Run Locally
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```
